# Keep The Ball Up 🎮

**Keep The Ball Up** is a lightweight 2D game developed using **C# and .NET Windows Forms**.

The goal of the game is simple: **keep the ball in the air for as long as possible** by clicking on it before it reaches the ground.

The game includes basic physics such as gravity, vertical movement, controlled horizontal movement, collision with the game boundaries, scoring, and a game-over system.

## 🛠️ Built With

* C#
* .NET
* Windows Forms
* Visual Studio

## 🎯 Gameplay

Click the ball to push it upward and keep it from touching the ground. The player's score increases with each successful hit.

## ✨ Features

* Simple 2D gameplay
* Ball physics and gravity
* Horizontal movement
* Mouse-based controls
* Score system
* Game Over detection
* Restart functionality
